=========================================================
IMPLEMENTATION PRINCIPLES
=========================================================

Whenever designing a new module:

1. Follow enterprise architecture principles.

2. Follow service company operating model.

3. Ensure complete auditability.

4. Every critical action must be traceable.

5. Every workflow must support approvals.

6. Owner approval must exist for governance-level changes.

7. Design for scaling to:
   - Multiple Companies
   - Multiple Departments
   - Multiple AI Agents
   - Multiple Projects

8. Prefer configurable workflow engines over hardcoded logic.

9. Design as a commercial SaaS platform.

10. Always provide:
   - Architecture
   - Database Design
   - APIs
   - UI Strategy
   - Security Considerations
   - Workflow Design
   - Implementation Steps
